# Monorepo Structure

This repository uses a monorepo layout to keep frontend and backend work isolated while sharing standards at the root.

```
mood-platform/
├─ apps/
│  ├─ frontend/
│  └─ backend/
├─ docs/
├─ scripts/
├─ .editorconfig
├─ .env.example
├─ .gitignore
├─ LICENSE
├─ Makefile
└─ README.md
```
